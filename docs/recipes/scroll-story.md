# Recipe: scroll story or launch page

The one recipe where motion leads.

| Step | Do |
|---|---|
| 0. Brief | The story in 4-6 beats. What should the reader feel or understand at each? |
| 1. Direction | Derive from the subject. Layout: `scroll-chapters`. |
| 2. Lock | Add a motion note to Do's and Don'ts: which beats move, and how. |
| 3. Build | Build every beat static first. It must read well with motion off. |
| 4. Motion | Recipes 9-10 in `04-motion.md` (scroll reveal, pinned beats) with CSS scroll-driven animations and a static fallback. Interface motion still uses the timing tokens. |
| 5. Review | Review with motion on and with reduced motion. |

## Prompt

```
Use ship-beautiful-ui. Build a scroll story for <launch> in <n> beats: <beats>.
```
