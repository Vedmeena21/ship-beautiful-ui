# Recipes

How to run the pipeline for common jobs. Every recipe follows the same six steps from [`SKILL.md`](../../skills/ship-beautiful-ui/SKILL.md); what changes is the route, the layout and how much motion is allowed.

| Recipe | Direction route | Layout | Motion |
|---|---|---|---|
| [Landing page](landing-page.md) | Derive from the subject | product-proof, type-hero or photo-led | One ambient moment |
| [Dashboard or web app](dashboard.md) | Library (`--kind saas`) or brand | dashboard-focus, settings-plain | Feedback only |
| [Mobile app](mobile-app.md) | Derive or library | form-first, signup-calm | Platform-native feedback |
| [Redesign an existing UI](redesign.md) | Existing brand | keep, then improve | Remove before adding |
| [Scroll story / launch page](scroll-story.md) | Derive from the subject | scroll-chapters | Scroll-driven beats |
